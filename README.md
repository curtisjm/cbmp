# CBMP

CBMP is a Next.js App Router application for collegiate ballroom Competition management. The root app shell is intentionally sparse while Clerk identity and Convex data behavior are added in follow-up slices.

## Development

- [Local setup](docs/development/local-setup.md)
- [Auth and data path boundaries](docs/development/auth-data-path.md)

Useful commands:

```sh
pnpm install
pnpm dev
pnpm typecheck
pnpm test:smoke
```
